# Recetario Git — Metodología de Sistemas II

Catálogo colaborativo de comandos de Git, construido por la comisión.
Cada estudiante aporta al menos un comando **vía fork + Pull Request**.

Sitio publicado: _(se completa después del primer release)_

## Qué necesitás

Solo **Git** y una cuenta de GitHub. XAMPP es opcional: sirve para validar tu aporte
antes de subirlo y para ver la página en tu máquina. Ver [XAMPP.md](XAMPP.md).

## Cómo aportar

Está todo en [CONTRIBUTING.md](CONTRIBUTING.md). El resumen:

1. Fork de este repo
2. Rama `comando/<tu-usuario>`
3. Un archivo nuevo en `comandos/<tu-usuario>.json`
4. Push a tu fork y Pull Request hacia `main`
